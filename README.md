**RAJ AI** is a high-performance desktop AI Chatbot and intelligent Java pair programmer developed for **Task 3** of the **CodeAlpha Java Programming Internship**. Built from scratch in **Java 17+** with a custom Swing UI/UX design system, rule-based NLP intent recognition engine, multi-turn conversation context tracking, live analytics dashboard, real-time knowledge base management, and thread-safe atomic local JSON persistence.

For detailed documentation, architecture diagrams, and test results, please refer to:
👉 [Task3_AIChatbot/README.md](Task3_AIChatbot/README.md)

---

## 🚀 Quick Run (Windows)

Double-click `run.bat` or run:
```cmd
run.bat
```

Or with Maven:
```cmd
mvn clean test
mvn package -DskipTests
java -jar Task3_AIChatbot/target/Task3_AIChatbot-1.0.0-jar-with-dependencies.jar
```
